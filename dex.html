Every released species in Pokémon GO (pvpoke gamemaster), one row per family at its first dex #. Cosmetic costumes are de-duplicated. League / Purpose lists every usage — each PvP league a form ranks in (LC top 50 / GL·UL top 100 / ML top 75), one line each. No usage → Collection only with the folded forms. A PvE line flags a family as a top raid attacker of a type, with its real PGHub rank + best form — top-6 catchable (or top-20 for a legendary/mythical/UB you own) per type. Catchable lines show up to three numbers: 1st = rank overall, 2nd = rank within the non-locked pool (legendary/mythical/UB excluded), 3rd = rank within the non-locked & non-shadow pool (shadow can't be traded, so this is the best you can catch a tradeable high-IV of). The top-6 by that 3rd rank are kept (e.g. Bug #7, #6, #5 = Mega Beedrill, 7th overall, 6th non-locked, 5th non-locked-non-shadow). A Mega only earns a PvE line if that Mega is actually a top attacker (no more blanket "has-a-Mega" flag).
