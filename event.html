Capped-PvP keeper bar — read Poke Genie's Rank % (the percentile, e.g. “Rank 85.64%”) — not the appraisal star %:
  • 🏆 Tournament / perfect — Rank % ≥ 97.6  (≤ #100)
  • ✅ Keep & main it (recommended) — Rank % ≥ 95  (≤ #205)
  • 👌 Fine if it’s your only copy — Rank % ≥ 88  (≤ #500)
…only for a top-~50 species that also reaches the CP cap. Master / Raid / Mega ignore this — use appraisal IV% ≥ 96 / 15 ATK.

Quick in-game search strings

Paste into the Pokémon GO search bar. +name = whole evolution line, 3*,4* = high IV (incl. hundos); IV stats use a 0–4 scale (3–4 = 11–15 IV). Order: run String 2 first, nickname each PvP keeper so its name contains pvp, THEN run Transfer — !pvp + !shiny + the 0*,1*,2* filter keep your tagged gems, shinies, and hundos safe.
